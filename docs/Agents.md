# Instrucciones del proyecto Ecomerce

## Documento principal de requisitos

Antes de desarrollar funcionalidades, consultar:

docs/condiciones_y_reglas_del_proyecto.md

## Reglas obligatorias

- Respetar los requisitos del catálogo virtual.
- Utilizar Laravel, Blade y Tailwind CSS.
- Utilizar PostgreSQL como base de datos final.
- Permitir SQLite para pruebas iniciales.
- Implementar autenticación de usuarios.
- Implementar catálogo, búsquedas y carrito.
- Validar las existencias antes de agregar productos.
- Inicializar la base de datos con al menos 20 artículos.
- Mantener documentación técnica en /docs.
- Respetar el cronograma establecido.
- Utilizar Pull Requests y revisión cruzada.
- No realizar commits ni push sin autorización.
